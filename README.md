# Private Equity OB/GYN Study: Data Pipeline

Data-engineering pipeline supporting the study **"Private vs. Public: Does Equity
Ownership Influence OB/GYN Appointment Wait Times?"** (COMIRB exempt; PI: Tyler
Muffly, MD; co-investigator: Taylor Gatson, MD).

The study uses a cross-sectional **mystery-caller** design: trained callers pose as
new patients and call OB/GYN clinics to compare new-patient appointment wait times
and insurance acceptance between **private-equity-backed** and **independent**
practices. This repository builds the sampling frame (the list of PE and matched
control clinicians to call), enriches it with NPI-registry and other public
metadata, draws the fielded sample, and produces the REDCap load files, study
figures, and manuscript. Mystery-caller outcome data is collected separately in
REDCap and is not part of this repo.

## Repository contents

This repo tracks **code, the IRB protocol, and the manuscript**. Bulk and derived
data files (CSVs, Excel, JSON, scraped HTML, provider rosters) are intentionally
gitignored: they are regenerated by the scripts below and, in some cases, derive
from licensed sources (e.g. PitchBook) or contain provider data that should not be
redistributed.

## Pipeline

### Track A: PitchBook company / deal universe (defines the PE exposure)

1. `extract.py` *(or `extract_applescript.py`)*: scrape PitchBook company/deal
   tables from a logged-in Chrome session, giving `companies_export.csv`, `deals_export.csv`.
2. `filter_pe_obgyn.py`: keyword-filter to OB/GYN-relevant rows.
3. `clean_data.py`: de-noise and drop false positives, giving `pe_obgyn_companies_clean.csv`, `pe_obgyn_deals_clean.csv`.

### Track B: Provider directory to NPI-matched PE cohort

4. `fetch_html_directories.py`: download PE-owned practice directory pages to `scraped_texts/`.
5. `parse_scraped_directories.py`: parse providers + PE metadata to `discovered_providers.json`.
6. `match_all_providers.py`: match providers to the CMS NPPES/NPI registry, enforce
   MD/DO and state validation, exclude mid-levels, and enrich.

`nppes_matcher.py` is an earlier standalone prototype, superseded by `match_all_providers.py`.

### Track C: Matched controls and the fielded sample

7. `export_control_candidates.py` + `build_matched_control_group_psm.R`: draw independent
   private-practice controls and 1-to-1 propensity-score match them within a 10-mile,
   same-state radius (gender, MD/DO, years in practice, Open Payments).
8. `subsample_300_pairs.R` / `build_200_redcap_import.R`: collapse to one physician per
   office and draw a geographically balanced fielded sample (round-robin across states,
   which caps Florida's over-representation).
9. `build_balanced_google_sheet.R`: write the caller list in Google Sheets import format
   (`mysterycall_export_gsheet_caller_list()`).

### REDCap

- `generate_redcap_data_dictionary.py` / `update_redcap_dictionary.py`: build the REDCap
  data dictionary for the call instrument.
- `build_200_redcap_import.R`: produce the fielded 200-pair set and its REDCap load files:
  `redcap_import_ready_200.csv` (records) and `redcap_physician_name_choices.txt` (the
  800 physician-by-insurance dropdown choices; ids 1-400 Medicaid, 401-800 Blue Cross/Blue Shield).

### Figures

`make_figures.R`, `make_figures2.R`, `make_polish.R`, and `fig3_simr.R` build the study
figures (sampling/matching flow, geographic map, power curves, and illustrative results
templates) into `figures/`, using the `mysterycall` package's Green Journal styling.

### Manuscript

`manuscript/` holds the pandoc-sourced manuscript. See `manuscript/README.md` for the
render command and conventions.

## Setup

```bash
pip install -r requirements.txt
```

R scripts use `mysterycall`, `readr`, `dplyr`, `ggplot2`, `MASS`, `simr`, and others.
The CMS NPI Registry API used for matching is public and requires no key.

### Optional external dependencies (enrichment only)

`match_all_providers.py` adds extra columns if these local resources are present, and
silently falls back to `N/A` if not:

- A local DuckDB database (e.g. `/Volumes/MufflySamsung 1/DuckDB/nber_my_duckdb.duckdb`).
- An ABOG subspecialty crosswalk CSV (e.g. `~/Desktop/canonical_abog_npi_LATEST.csv`).
- An R script for name-based gender inference.

Paths are hardcoded in `match_all_providers.py`; adjust them for your machine.
