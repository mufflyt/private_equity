# Private Equity OB/GYN Study — Data Pipeline

Data-engineering pipeline supporting the study **"Private vs. Public: Does Equity
Ownership Influence OB/GYN Appointment Wait Times?"** (COMIRB exempt; PI: Tyler
Muffly, MD; co-investigator: Taylor Gatson, MD).

The study uses a cross-sectional **mystery-caller** design: trained callers pose as
new patients and call OB/GYN clinics to compare new-patient appointment wait times
and insurance acceptance between **private-equity-owned** and **publicly-owned**
practices. This repository builds the sampling frame — the list of PE-owned and
control providers/clinics to call — and enriches it with NPI-registry and other
public metadata. Mystery-caller outcome data is collected separately in REDCap and
is not part of this repo.

## Repository contents

This repo tracks **code and the IRB protocol only**. All data files (CSVs, Excel,
JSON, scraped HTML) are intentionally gitignored — they are regenerated by the
scripts below and, in some cases, derive from licensed sources (e.g. PitchBook) or
contain bulk provider data that should not be redistributed.

## Pipeline

### Track A — PitchBook company / deal universe (defines the PE exposure)

1. `extract.py` *(or `extract_applescript.py`)* — scrape PitchBook company/deal
   tables from a logged-in Chrome session → `companies_export.csv`, `deals_export.csv`.
2. `filter_pe_obgyn.py` — keyword-filter to OB/GYN-relevant rows → `pe_obgyn_companies_filtered.csv`, `pe_obgyn_deals_filtered.csv`.
3. `clean_data.py` — de-noise and drop false positives → `pe_obgyn_companies_clean.csv`, `pe_obgyn_deals_clean.csv`.

### Track B — Provider directory → NPI-matched cohort (the call frame)

4. `fetch_html_directories.py` — download PE-owned practice directory pages → `scraped_texts/*.html`.
5. `parse_scraped_directories.py` — parse providers + PE metadata → `discovered_providers.json`.
6. `match_all_providers.py` — match providers to the CMS NPPES/NPI registry, enforce
   MD/DO and state validation, exclude mid-levels, and enrich → `pe_obgyn_providers_npi.csv`.

`nppes_matcher.py` is an earlier standalone prototype of the NPI matcher, superseded
by `match_all_providers.py`.

## Setup

```bash
pip install -r requirements.txt
```

The CMS NPI Registry API used for matching is public and requires no key.

### Optional external dependencies (enrichment only)

`match_all_providers.py` will add extra columns if these local resources are present,
and silently falls back to `N/A` if they are not:

- A local DuckDB database (e.g. `/Volumes/MufflySamsung 1/DuckDB/nber_my_duckdb.duckdb`)
  for NPPES/Open Payments/DAC enrichment.
- An ABOG subspecialty crosswalk CSV (e.g. `~/Desktop/canonical_abog_npi_LATEST.csv`).
- An R script for name-based gender inference.

Paths to these are hardcoded in `match_all_providers.py`; adjust them for your machine.
